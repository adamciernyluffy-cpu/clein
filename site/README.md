# Aether Client website

Static, responsive landing page with animated glass-style product mockup.

## Publish
- Update `REPOSITORY_URL` in `script.js` to your actual GitHub repository.
- Update the GitHub links in `index.html` if you want a custom release destination.
- Publish the `site/` folder with GitHub Pages, Netlify, or any static hosting provider.

The product mockup is illustrative; it is not a live screenshot from the Minecraft client. Download links point to GitHub until you configure your repository and publish a real release.
